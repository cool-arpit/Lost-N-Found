# FindIt — Smart Campus Recovery Network

A polished React + Vite campus lost-and-found prototype built for an interview task.

## Run locally

```bash
npm install
npm run dev
```

Open the Vite localhost URL in your browser.

## Included

- Lost / found reports with validation and optional image upload
- Search, category, type and location filters
- Rule-based Smart Match engine (category, location, date, description)
- Explainable match scores
- Campus Pulse analytics and visual campus hotspot map
- Recovery timeline concepts and safe handover verification flow
- Notifications and match alerts
- Personal reports with edit, delete and recovered states
- Profile editing and dark/light mode
- LocalStorage persistence, so no API key is needed

## Demo data

The first launch contains sample campus reports so the matching engine and analytics are immediately visible. Your own reports are stored locally in the browser.
